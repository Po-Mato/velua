# 벨루아 · 잔광의 성역

[게임 플레이](https://po-mato.github.io/velua/)

브라우저에서 실행하는 솔로 방치형 RPG입니다. 이 저장소에는 서비스용 빌드 결과물만 보관합니다. 원본 소스, 제작 중간 파일과 개인 플레이 기록은 포함하지 않습니다.

- 이동: WASD / 방향키 / 바닥 클릭
- 스킬: Q E R T Y U / 회피: Space
- 메뉴: M / 화면 정리: H / 자동 추적: F
- 저장: 브라우저 자동 저장. 설정에서 JSON 내보내기·가져오기로 다른 주소나 기기로 기록을 옮길 수 있습니다. 계정 기반 동기화는 제공하지 않습니다.

배포는 Actions의 Publish game to GitHub Pages를 수동 실행합니다. site 디렉터리만 게시하며 build-info.json으로 배포 커밋을 확인할 수 있습니다.

자산 출처와 라이선스는 site/fonts, site/vfx, site/art 및 site/ui의 CREDITS와 LICENSE 파일을 참고하세요. 별도 라이선스가 없는 게임 코드와 원본 제작 자산의 재배포 권한을 허여하지 않습니다.
