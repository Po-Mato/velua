# Velua combat VFX credits

Player skill visuals are baked from Effekseer CC0 contributed presets by **tktk** and **Pierre**. See [the player effect source list and transformations](effekseer/CREDITS.md).

Monster and boss visuals combine native Effekseer animation with original imagegen elemental artwork. See [the enemy source list and transformations](enemy/CREDITS.md).

The earlier Cethiel / Mikodrak / para sheets are retained in `artifacts/vfx-legacy-atlases/` with their original credits. They are no longer downloaded or used by the game. Canvas fallback visuals remain available if image assets fail.
